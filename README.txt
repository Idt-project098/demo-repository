CampusSubmit - simple one-device version

QUICK START (Windows)
1. Extract the zip. Keep all files in the same folder.
2. Double-click setup.bat once. It puts a CampusSubmit shortcut on your Desktop.
3. From then on, double-click the Desktop shortcut, or start.bat, to open the app.

You can also just double-click index.html. No internet or database setup is needed.
If Windows shows a warning for setup.bat or start.bat, click "More info" then "Run anyway". These are plain text scripts and you can open them in Notepad to check.

Logins
- Teacher: teacher@098
- Student: first name + @123 (e.g. Aryan@123), choose the name from the list

How it works
- Teacher and students use the same browser on the same device. Open one window as the teacher and another as the student (or switch tabs). Both see the same assignments, submissions, doubts and replies.
- Files up to 10 MB are saved in the browser, so students and teacher can open them from links.
- Everything is saved automatically. Do not clear the browser's site data, or the saved work will be lost.

Limits
- Works on this device and browser only. It does not sync to other computers or phones.
- Passwords are simple demo passwords.

Supabase version (for sharing across devices later) is in the folder CampusSubmit_supabase_version.
